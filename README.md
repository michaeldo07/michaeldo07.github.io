# Michael Do’s portfolio

Personal site for my software projects, research, and engineering experience at Georgia Tech.

**Live site:** [michaeldo07.github.io](https://michaeldo07.github.io/)

The site is a single HTML file. Its stylesheet and portrait are embedded, so you can preview it without installing packages or setting environment variables.

```sh
python3 -m http.server 8000
```

Run that command from the repository root, then open [localhost:8000](http://localhost:8000).
